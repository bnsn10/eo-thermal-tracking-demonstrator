# Safety Notes

This project is a stationary tabletop demonstrator for learning perception, controls, embedded systems, CAD, and test methods.

## Boundaries

- No flight testing.
- No propulsion.
- No weaponization.
- No guidance-to-impact behavior.
- No outdoor operational deployment.

## Bench Safety Practices

- Use low-voltage power appropriate for selected servos and electronics.
- Keep servo torque and range of motion conservative.
- Add software command limits before closed-loop testing.
- Use a manual power disconnect during tests.
- Keep hands, wires, and loose parts clear of moving linkages.
- Stop testing if a servo binds, overheats, jitters unexpectedly, or loses command.

## Documentation Practice

Each test should record the setup, power source, hardware version, software version, command limits, and any observed issues.
