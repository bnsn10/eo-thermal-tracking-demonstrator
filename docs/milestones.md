# Milestones

## Milestone 1: Requirements and Safety

- Define project scope and safety boundary.
- Select tabletop architecture: gimbal, fin-control fixture, or both.
- Draft initial risk notes and test constraints.

## Milestone 2: Sensor and Tracking Prototype

- Capture sample visible or thermal frames.
- Implement target center detection.
- Output x/y error relative to image center.

## Milestone 3: Mechanical CAD

- Model base, sensor mount, servo mount, and control-surface fixture in Fusion 360.
- Export renders and drawings for the portfolio.
- Validate range of motion and cable clearance.

## Milestone 4: Embedded Servo Control

- Drive servos from a microcontroller.
- Add command limits and a neutral/failsafe state.
- Log command and response data.

## Milestone 5: Closed-Loop Bench Test

- Connect tracking output to servo command logic.
- Tune proportional or PID behavior on a low-energy bench setup.
- Record step response and tracking response data.

## Milestone 6: Portfolio Report

- Publish architecture diagram, CAD renders, photos, plots, and lessons learned.
- Summarize tradeoffs and future improvements.
